# Constructorfleet branding

Source: `constructorfleet/cf-branding@217f74462ef4d965872ac9e0419f692a3a44d903`.

The dashboard packages the approved reduced stacked-header PNG plus the lightweight SVG favicon and maps its inline UI variables to the shared semantic palette. Both assets are served by the controller itself, so the dashboard has no branding runtime dependency.

Update the source repository first, replace the delivery asset copies, then run the test suite and inspect light, dark, desktop, and narrow layouts. Do not edit the logo artwork independently here.
