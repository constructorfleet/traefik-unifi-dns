# Constructorfleet branding

Source: `constructorfleet/cf-branding@ff83c4015854817c22c15c3945661f46ce90c979`.

The dashboard packages the approved lightweight SVG icon and maps its inline UI variables to the shared semantic palette. The icon is served by the controller itself, so the dashboard has no branding runtime dependency.

Update the source repository first, replace the SVG copy, then run the test suite and inspect light, dark, desktop, and narrow layouts. Do not edit the logo artwork independently here.
